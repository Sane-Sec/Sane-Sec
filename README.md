# Sane Aboubaker — Cybersecurity Portfolio

Personal portfolio website for **Sane Aboubaker**, Cybersecurity Consultant / Red Team Analyst / SOC Analyst.

🔗 Live sections: Home · About Me · Experience · Parcours Académique · Skills · Services · Hard Skills · Projects · Certification · Contact

##  About

This site presents my profile, background, technical skills, professional experience, and certifications in cybersecurity — with a focus on SOC monitoring, penetration testing, and threat analysis.

##  Sections

- **Home** — Introduction, CV download, social links (GitHub, LinkedIn)
- **About Me** — Bio, soft skills
- **Experience** — Professional experience (MDR Security Analyst, Jr Penetration Tester, SOC Analyst)
- **Parcours Académique** — Academic background
- **Skills & Experience** — Technical skill levels (Penetration Testing, Network Defense, Digital Forensics, Incident Response, etc.)
- **Services** — Services offered
- **Hard Skills** — Tools & technologies
- **Projects** — Featured work
- **Certification** — Certifications and credentials (CRTA, eJPTv1, CCNP Security, etc.)
- **Contact** — Get in touch

##  Built With

- HTML5 / CSS3
- Bootstrap 5
- JavaScript (jQuery)
- Owl Carousel, Lightbox, WOW.js/Animate.css
- Font Awesome & Bootstrap Icons

## Project Structure

```
├── index.html          # Main page
├── css/
│   ├── bootstrap.min.css
│   └── style.css
├── img/                 # Images, photos, logos
├── lib/                 # Third-party libraries (animate, lightbox, owlcarousel)

```

## Customization

- Update text content directly in `index.html`.
- Replace images in `img/` (keep the same filenames, or update the `src` paths).
- Adjust colors/spacing in `css/style.css`.
- Swap the CV file in `doc/` and update the download link in the Home section.
